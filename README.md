# WE MOVE website

Next.js 14 + Tailwind CSS. Verhuizen en Sjouwhulp & Hospitality in één site.
Website door [kogi.nl](https://kogi.nl).

- Bedrijfsgegevens: `src/lib/site.ts`
- Teksten per tak: `src/lib/branches.ts`
- Google-reviews (alleen echte): `src/lib/reviews.ts`
- Pagina's: `src/app/*`
